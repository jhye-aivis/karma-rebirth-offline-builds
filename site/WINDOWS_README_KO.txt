KARMA REBIRTH WAVE 16 — Windows 10/11 오프라인 플레이 안내

1) 다운로드 받은 ZIP 파일을 먼저 모두 압축 해제하세요. ZIP 안에서 직접 실행하면 경로 오류가 발생할 수 있습니다.
2) 압축을 푼 폴더의 PLAY_WINDOWS.bat 파일을 더블클릭합니다.
3) PowerShell 콘솔이 나타나면서 기본 웹 브라우저에서 http://127.0.0.1:8877/three-d/index.html 이 열립니다.
4) 인터넷 연결·관리자 권한·Python·Node·Steam 설치가 필요하지 않습니다. Windows 기본 PowerShell 5.1과 Chrome/Edge WebGL2 사용 환경이 필요합니다.
5) WASD 이동, Shift 달리기, Ctrl 앉기, Q 1·3인칭 전환, 마우스 좌클릭 사격, R 재장전, ESC 일시정지입니다.
6) 게임을 종료하려면 콘솔 창에서 Ctrl+C를 누르거나 콘솔 창을 닫으세요.

주의: 실행 스크립트는 현재 PC의 127.0.0.1:8877에만 연결하는 로컬 파일 서버입니다. 방화벽 포트 공개/외부 통신은 하지 않습니다.
Windows PowerShell은 압축으로 다운로드한 외부 스크립트 실행을 제한하는 경우가 있으므로, 이 배치 파일은 해당 실행 1회에 한해 -ExecutionPolicy Bypass를 사용합니다. 신뢰 가능한 ZIP인지 확인한 뒤 직접 실행하세요.
PowerShell 정책이 조직에 의해 제한된 PC에서는 실행이 거부될 수 있습니다. 다른 프로그램이 8877 포트를 점유했다면 그 프로그램을 닫아야 합니다.

Windows 네이티브 바이너리(.exe)가 아닌 브라우저 WebGL2 FPS입니다. 실제 Windows PC에서의 프레임 성능·그래픽 드라이버 적합성은 별도 검증 대상입니다.
원작의 상용 영상·모델은 배포 대상에 포함하지 않습니다. 독일군은 원 제작자 CC0 실사형 Panzergrenadier 메시의 최적화 GLB가 적용되어 있습니다. 실사형 MP40/PPSh 무기 및 소련군 캐릭터 교체는 아직 완료되지 않았습니다. 기본 빠른 모드에서 독일군 AI는 성능을 위해 경량 모델로 표시됩니다.

Wave18: 게임 우측 하단의 성능·FPS·피드백 버튼에서 실제 FPS를 확인하고 그래픽 모드를 선택할 수 있습니다.

Wave19: 실제 이 Windows PC의 Chrome GPU / Wave17 vs 최신 A/B 성능 비교는 COMPARE_WINDOWS.bat을 사용하세요. 최초 실행은 공식 v0.17.0 ZIP 약 48.5MB를 GitHub에서 가져오며 인터넷이 필요합니다. 다운로드받은 ZIP을 검사한 다음 비교 페이지를 로컬로 띄웁니다. 결과 JSON은 자동 전송되지 않으며 본인이 다운로드 후 공유를 선택합니다. Windows CI 서버 테스트는 본인 PC GPU 플레이 성능과 다릅니다.

Wave20: 게임 메인 메뉴의 Chrome 실제 녹화 MP4 링크에서 걷기·사격·재장전 영상 전후 좌우 비교가 가능합니다. 독일군 한손/임시 탄창 파지 IK 오차를 감소시켰으나 소련군/실사 총기 모델은 미적용입니다.
